# 💡 Clarity — Digital Solutions Landing Page

A fully responsive landing page for a digital solutions agency, built with Bootstrap 5 and custom CSS.

**🔗 Live Demo:** https://jamalmahran.github.io/clarity-landing-page/

![Clarity preview](./screenshots/preview.png)

## ✨ Sections

- **Navbar:** fixed navbar with a mega menu dropdown that adapts to mobile
- **Hero:** headline, call-to-action buttons, and floating icon accents
- **Services:** service cards with hover animations
- **Technology Stack:** tabbed view for Frontend, Backend, Mobile, Cloud, and Database
- **Testimonials:** client reviews in a Bootstrap carousel
- **FAQ:** accordion with custom-styled toggle icons
- **Contact:** multi-field form with dropdowns, budget options, and a consent checkbox
- **Footer**

## 🛠️ Built With

- HTML5
- CSS3 (custom properties, Flexbox, transitions)
- Bootstrap 5 (grid, navbar, tabs, carousel, accordion, forms)
- Font Awesome

## 📱 Responsive Design

The layout is mobile-first using the Bootstrap grid, with extra breakpoints in `css/media.css` for the navbar mega menu, typography, container widths, and the contact form layout.

## 🚀 Run Locally

```bash
git clone https://github.com/jamalmahran/clarity-landing-page.git
cd clarity-landing-page
```

Then open `index.html` in your browser.
